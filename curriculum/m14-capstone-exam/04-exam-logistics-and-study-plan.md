# M14-04. 시험 접수·당일 가이드, 문제 풀이 기술, 오답 노트, 마지막 1주
> 도메인: D1~D4 · 예상 시간: 40분 (+ 모의고사 130분, 오답 정리 2~3시간) · 실습 등급: — (문서)

## 왜 필요한가

실력이 있어도 시간 배분을 망치거나, 복수 응답 문항에서 하나만 고르거나, 접수 규정을 몰라 응시료를 날리면 결과가 달라진다. 이 레슨은 시험장 밖의 일(접수·규정·당일)과 시험장 안의 일(문제 읽기·시간 관리)을 정리하고, [모의고사](./mock-exam/questions.md) 결과를 마지막 1주의 복습 계획으로 바꾸는 방법을 준다.

## 핵심 개념

### 2. 접수부터 당일까지

1. **계정**: [aws.training/Certification](https://aws.training/Certification)에 로그인(AWS Builder ID 등) → Schedule an exam → SAA-C03 → 방식(센터/온라인)·언어 선택 → Pearson VUE에서 날짜 예약·결제.
2. **영어로 응시하는 비원어민**은 **ESL +30분** 편의를 **접수 전에** 한 번 신청해 둔다(Certification 계정 → Request Exam Accommodations → `ESL +30 MINUTES`). 이후 모든 영어 응시에 적용된다. 한국어로 응시하면 필요 없다.
   - 한국어판과 영어판 중 고르기: 서비스 이름·API는 영어 원문이고 지문은 번역이다. 이 커리큘럼처럼 "한국어 설명 + 영어 서비스명"에 익숙하면 한국어판, 영어 원문이 편하면 영어판 + ESL 30분.
3. **일정 변경·취소**: 예약 시각 **24시간 전까지** 변경 가능(예약당 최대 2회). 24시간 이내 취소·불참은 응시료를 잃는다.
4. **신분증**: 거주를 증명하는 유효한 정부 발급 신분증 + 보조 신분증. 응시 국가 발급 신분증이 없으면 국적국 여권이 주 신분증. 온라인과 센터의 요구가 다를 수 있으니 예약 확인 메일을 따른다.
5. **온라인 감독이면**: 전날 Pearson VUE의 시스템 점검(웹캠·마이크·네트워크)을 미리 실행하고, 책상 위를 비우고, 방에 혼자 있을 수 있는 시간을 잡는다. 회사 노트북은 보안 소프트웨어 때문에 실패하기 쉽다.
6. **불합격 시**: **14일** 뒤 재응시 가능, 응시료는 매번 전액. 합격한 시험은 2년간 같은 시험을 다시 볼 수 없다.
7. **결과**: 점수 보고서에 도메인별 수행 수준이 나온다(문항 수가 적어 해석에 주의). 합격자는 디지털 배지를 받는다.

### 3. 문제 읽기 기술

모의고사 해설이 반복해서 쓴 방법을 순서로 정리하면:

1. **마지막 문장부터 읽는다** — "가장 비용 효율적인", "운영 부담이 가장 적은", "가용성이 가장 높은", "두 개를 고르시오". 무엇을 최적화하는지와 고를 개수를 먼저 안다.
2. **제약에 밑줄** — 숫자(RTO 1시간, 48시간 안에, 초당 300건), 금지(인터넷을 거치면 안 됨, 코드 변경 최소, 장기 키 금지), 기존 조건(JMS, SMB·AD, Kafka).
3. **신호어 → 서비스** — [치트시트](./cheatsheet.md)의 표가 이 매핑이다. "순서 + 중복 없음" → FIFO, "여러 시스템이 각자" → SNS + SQS, "밀리초 + 드물게" → Glacier IR, "고정 IP + UDP" → Global Accelerator.
4. **보기를 지운다** — 제약을 하나라도 깨면 아무리 좋아 보여도 탈락. 가장 싼 보기·가장 강력한 보기가 함정인 경우가 많다(Deep Archive는 싸지만 "즉시"를 깨고, 다중 사이트는 강하지만 "비용 최소"를 깬다).
5. **남은 두 개에서 고민되면** — 관리형·서버리스·자동화 쪽, 그리고 **요구보다 과하지 않은** 쪽.
6. **복수 응답** — 정답들은 보통 **서로 다른 문제를 하나씩** 푼다(모의고사 28번: 백업용 하나, S3용 하나). 같은 말을 두 번 하는 보기 두 개는 함께 정답일 가능성이 낮다. 부분 점수가 없다.
7. **지문에 없는 가정을 보태지 않는다** — "아마 트래픽이 늘겠지"처럼 지문에 없는 조건으로 답을 바꾸지 않는다.

### 4. 시간 관리 (130분 / 65문항 = 문항당 2분)

| 구간 | 할 일 |
|---|---|
| 1회전 0~85분 | 모든 문항을 한 번씩. **1분 30초 안에 확신이 없으면 가장 그럴듯한 답을 찍고 "검토 표시(flag)"** 후 넘어간다. 빈칸 금지 |
| 체크포인트 | 30분에 약 22번, 60분에 약 44번, 85분에 65번 |
| 2회전 85~120분 | 검토 표시한 문항만. 처음 답을 바꾸는 것은 **명확한 근거(놓친 제약)를 찾았을 때만** |
| 마지막 10분 | 무응답이 없는지, 복수 응답의 개수를 맞게 골랐는지 확인 |

모의고사는 반드시 **한 번에 130분**으로 푼다. 집중력이 떨어지는 50번 이후의 정답률이 실제 약점일 때가 많다.

### 5. 모의고사 → 채점 → 오답 노트

```bash
cp curriculum/m14-capstone-exam/mock-exam/answer-sheet.txt my-answers.txt   # 답을 채운다 (확신 없으면 '17 C?')
uv run python curriculum/m14-capstone-exam/mock-exam/grade.py my-answers.txt
```

정답표를 그대로 넣었을 때의 실제 출력(채점기 자가 시험, `verify.sh`가 매번 확인):

```text
도메인별 결과
  D1 보안 아키텍처        20/20 100.0%  ████████████████████
  D2 복원력 있는 아키텍처    17/17 100.0%  ████████████████████
  D3 고성능 아키텍처       15/15 100.0%  ████████████████████
  D4 비용 최적화 아키텍처    13/13 100.0%  ████████████████████

전체 65/65 = 100.0%   (무응답 0문항)
판정: 통과 — 이 커리큘럼의 기준(정답률 72% 이상, CURRICULUM §7)을 넘었다.
주의: 실제 시험의 720점은 100~1,000 환산 점수이고 채점 대상 50문항 기준이라 정답률과 1:1로 대응하지 않는다.
```

틀린 문항이 있으면 `틀린 문항` 목록(번호·도메인·과제·내 답·정답·주제)과, `?`를 붙였는데 맞힌 "운으로 맞힌 문항" 목록이 이어서 나온다. **둘 다** 오답 노트에 옮긴다.

#### 오답 노트 템플릿

한 문항에 한 블록. 핵심은 "정답이 무엇인가"보다 **"나는 왜 다른 보기를 골랐나"**다.

```markdown
### 모의고사 17번 — D2 2.2 — 파일럿 라이트
- 내 답: B (웜 스탠바이)   정답: C
- 놓친 제약: "DR 리전은 평상시 트래픽을 받을 필요가 없다" + "가장 비용이 적게"
- 내가 한 착각: RPO 5분이면 무조건 상시 실행 스택이 필요하다고 생각함
- 바로잡은 규칙: RPO는 **데이터 복제**가, RTO는 **컴퓨트 기동 시간**이 결정한다. 두 축을 따로 본다
- 같은 함정의 다른 문항: 모의고사 37번(DR 서비스), M12 레슨 2 워크시트
- 복습한 곳: M12-02 DR 전략 표 · 다시 풀 날짜: D-3
```

| 놓친 이유 분류 | 처방 |
|---|---|
| 개념을 몰랐다 | 해설의 "복습" 링크 레슨을 다시 읽고, 그 모듈 퀴즈를 다시 푼다 |
| 개념은 알았는데 제약을 놓쳤다 | 3절 1~2단계(마지막 문장·밑줄)를 다음 모의고사에서 의식적으로 |
| 두 보기 사이에서 틀렸다 | 치트시트의 해당 비교표("아닌 것" 열)를 외운다 |
| 시간에 쫓겼다 | 1회전 1분 30초 규칙을 지킨다 |

### 6. 마지막 1주 계획

모의고사는 **D-7**에 처음 풀고, 결과의 도메인별 점수로 D-6~D-2의 순서를 정한다(가장 낮은 도메인부터). 기준: 전체 72% 이상(CURRICULUM §7), 도메인별 65% 미만이면 그 도메인을 우선.

| 날 | 할 일 | 모듈 |
|---|---|---|
| D-7 | 모의고사 130분 → 채점 → 오답 노트 작성 | 이 레슨 |
| D-6 | **D1 보안**: 정책 평가·SCP·역할 / 암호화·KMS·비밀 / 탐지 서비스 한 줄 구분. 각 모듈 퀴즈 다시 | M01, M09, (M02 SG·NACL·엔드포인트, M04-04) |
| D-5 | **D2 복원력**: 디커플링 선택표 / Multi-AZ vs 복제본 / DR 4전략 / 라우팅 정책 | M06, M05-02, M12, M08-02, M03-06 |
| D-4 | **D3 고성능**: 스토리지 선택(EBS·EFS·FSx·S3 클래스) / DB 선택 / 캐시 / 엣지 / 분석·AI 한 줄 매칭 | M04, M05, M03, M08, M11 |
| D-3 | **D4 비용**: 구매 옵션 / 스토리지 클래스·수명 주기 / 데이터 전송 지도 / 비용 도구. 오답 노트의 "다시 풀 날짜"가 D-3인 문항 | M13, M03-02, M04-02 |
| D-2 | 오답 노트 전체를 다시 풀기(보기를 가리고 정답과 **이유**를 말로). 캡스톤 [자기 점검표](./capstone-self-check.md) 마무리 | 이 모듈 |
| D-1 | [치트시트](./cheatsheet.md)의 "최근 바뀐 사실"과 숫자 모음만 훑고 일찍 잔다. 새 문제를 풀지 않는다 | — |
| D-day | 신분증·확인 메일. 온라인이면 30분 전 체크인. 4절 시간표대로 | — |

모의고사를 두 번째로 풀 때는 정답을 외웠으므로 점수가 의미 없다. 대신 **각 보기가 왜 틀렸는지 말로 설명**할 수 있는지를 본다 — 해설의 "오답이 틀린 이유"를 가리고 말해 본 뒤 대조한다.

## 실제 AWS에서는

- 시험은 AWS 콘솔을 쓰지 않는다. 하지만 "에뮬레이터에서 직접 만들어 본 것"은 보기를 지울 때 큰 힘이 된다 — 예: 게이트웨이 엔드포인트가 라우팅 테이블 경로라는 것(M02 lab06), DLQ가 같은 종류의 큐라는 것(M06 lab02), 가시성 타임아웃 < 함수 타임아웃이면 매핑이 거부된다는 것(M07 lab02).
- 프리 티어로 🟡/🔴 실습 몇 개를 실제로 해 보고 싶다면, 비용이 거의 없는 것부터: Route 53 상태 확인 장애 조치(M08), CloudFront + OAC(M08), Config 규칙(M09), Well-Architected Tool(레슨 01). NAT 게이트웨이·RDS Multi-AZ·ALB는 시간당 과금이므로 만들자마자 지운다.

## 시험 포인트

- 65문항 중 15문항은 채점하지 않지만 어느 것인지 모른다. 전부 진지하게, 빈칸 없이.
- 복수 응답은 개수가 정해져 있고 부분 점수가 없다.
- 합격선 720은 환산 점수다. 모의고사 72%는 이 커리큘럼의 자체 기준일 뿐이다.
- 문항당 평균 2분. 막히면 찍고 표시, 나중에.
