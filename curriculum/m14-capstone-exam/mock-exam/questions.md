- D. 정산 서버의 보안 그룹 아웃바운드 규칙을 S3의 접두사 목록(prefix list)으로만 제한한다.

- B. AWS Config 규칙으로 승인되지 않은 리전의 리소스를 찾아 알림을 보낸다.

- D. 조직 루트(또는 해당 OU)에 승인된 리전 이외의 요청을 `aws:RequestedRegion` 조건으로 거부하는 서비스 제어 정책(SCP)을 붙인다. 글로벌 서비스는 `NotAction`으로 예외 처리한다.
